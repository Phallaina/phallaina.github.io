Markdown 风格预览 · 星鲸长吟

以太之间，星鲸长吟。这一篇，是写给排版与文字的一封短信——用来看看，正文里的各种标记会以怎样的面目停泊。

标题之下

Markdown 的标题从大到小排开。一级标题通常用在文章标题，二级标题用来划开一节，三级标题再往里收一收。在这套风格里，一级标题居中、下方有一道细线；二级标题左侧竖着一道主题色，像海平线。

三级标题，颜色微深

四级标题，再淡一档

强调与情绪

一段文字里，想让它沉下去就用加粗——蓝灰色的、不吵闹的；想让它轻一点，就用斜体，像一句没说出口的话。

引用

别人说过的话，或是自己的某句独白，放进引用块里：

我渺小，但我的孤独可以装得下整片星海。 —— 祈里

清单

要一件一件做的事，或一个又一个念头：

  • 凌晨一点的冰箱嗡鸣
  • 雨夜窗前发呆的自己
  • 没说出口的那句喜欢

也可以是有顺序的：

  1. 先让思绪沉下来
  2. 再沿着看不见的线慢慢走
  3. 不为到达，只为途经

链接与代码

去读一篇关于孤独的碎念，或者回到星吟首页。

行内代码是这样：data-theme="dark" 与 --accent。代码块则是整段：

# 星鲸在以太中缓慢游弋
for star in galaxy:
    if star.is_distant():
        whale.sing(star)
    # 沉默、悠远、永不停歇

图片

图片会居中、带圆角和细边框，下可配一行说明文字。

星鲸头像，如此这般。

分割线与表格

一段话说完，用一道细短的分割线隔开，像翻过一页：

有些时候，也想把几件事并排摆成一张表：

时间星名轨迹
深夜祈里缓慢游弋
凌晨法伊那穿行群星
破晓前Phallaina沉默长吟

如此，便是这一套标记的样貌了。它们不喧哗，只安静地停在文字该在的地方。

Markdown 用法说明 · 写给写字的你

这一篇是给站内写作准备的用法清单。Markdown 是一种轻量的标记语言，用几个符号就能排出层次，这里把常用的一些列出来，供随手查阅。

标题

行首加 # 到 ######，表示一至六级标题，# 越多字号越小。本站建议正文里用到四级以内即可：

# 一级标题
## 二级标题
### 三级标题
#### 四级标题

一级标题会居中并带一道细线，二级标题左侧有主题色竖线，三级标题颜色微深。

强调

用一对 ** 包住文字是加粗，一对 * 是斜体：

**加粗** 和 *斜体*

加粗会以蓝灰色呈现，比纯黑更安静。

引用

行首用 > 表示引用块，可多层嵌套，也可在末尾加署名行（<cite>）：

> 这里是一句引语。
> <cite>—— 出处</cite>

列表

无序列表用 -、* 或 + 开头，有序列表用 1. 2. 开头：

- 第一项
- 第二项

1. 第一步
2. 第二步

无序项的符号会显示为一颗小星，有序项用衬线数字。

链接与图片

链接写 [文字](网址)，图片在链接前加一个 !：

[一段链接文字](https://example.com)
![图片说明](/images/starwhale-about.png)

图片会自动居中、加圆角和细边框，可用 <figcaption> 配一行说明。

行内代码与代码块

行内代码用一对反引号 ` 包住；整段代码块用三个反引号包住，可指定语言：

这是行内代码：`--accent`

```python
print("这是一段代码块")
```

行内代码为蓝灰字加浅底，代码块用深靛蓝星空底色。

分割线

三个及以上的 -、* 或 _（单独成行）会生成一道分割线：

---

本站分割线是一道居中的细短横。

表格

用竖线 | 和短横 - 拼出表头与表体：

| 表头一 | 表头二 |
| --- | --- |
| 内容一 | 内容二 |

表格带淡蓝灰表头、斑马纹与细边框。

小结

记住「符号即结构」就够了：# 划层级，**、* 表强调，> 引他人言，-/1. 列清单，反引号给代码，--- 分段落，| 排成表。愿你写下的每一段，都停在文字该在的地方。
