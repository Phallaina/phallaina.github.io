关于 Mist

Mist 是这个博客的第三个主题，也是我最想留下来的一个名字。

它不是设计出来的，是慢慢长出来的。最初只是想要一个能安静放文章的地方，不要花哨，不要卡片堆叠，不要那些一眼就能看出"这是模板"的装饰。改了十几轮之后，它终于有点像我说话的样子了。

它想成为什么

Mist 是一层薄薄的雾。

它不抢戏。你打开页面，眼睛先落在文字上，而不是落在边框、阴影、渐变色上。它存在的意义，是让文字自己浮出来。

配色上克制到几乎吝啬：九成是中性色——暖白的底、深褐的字、灰棕的次要文字；只有一成是陶土色，留给链接、当前页、那些需要被轻轻点一下的地方。没有高饱和，没有廉价渐变，没有格子卡片。

排版上的坚持

正文每段缩进两字符，行距放到 1.95。这是写给手机和深夜的——字可以小一点，但呼吸要够。

标题用衬线（Noto Serif SC），正文用无衬线（Noto Sans SC）。标题稍微重一点，正文轻一点，层级靠字号和字重，不靠颜色轰炸。

文章页左侧有一条窄窄的目录，跟着滚动高亮当前章节。它不占地方，像一个安静的向导。

它记得你读过哪里

往下滚一点，右下角会冒出一个圆形的回到顶部按钮。不用滚很远，只要页面动了一下，它就在那里了。

目录会记住你读到哪一段，当前章节会用一条细细的陶土色线标出来。这些都不是什么大功能，但让翻长文这件事变温柔了。

短代码是写给自己的笔记工具

关于短代码
写长文时总会需要一些小工具：折起来的题外话、一个小提示、一个按钮、一张 GitHub 卡片、几个并排的标签页。Mist 把它们都做成了短代码，写文章时随手插一句就有。

目前有的：

  • {{< collapse title="..." >}} —— 折叠框，放长引文
  • {{< tag >}} —— 行内小标签
  • {{< note title="..." >}} —— 小提示
  • {{< btn >}} —— 按钮链接
  • {{< github >}} —— GitHub 仓库卡片
  • {{< tabs >}} —— 多标签页

这些都在 {{< relref “/posts/shortcodes” >}}短代码速查{{< /relref >}}里演示过，写文章时翻一眼就行。

碎片是一条时间轴

为什么有碎片这个 section
不是每句话都值得写成一篇长文。有些念头很短，像海边一句没说完的话。碎片页就是放这些短念头的地方，做成时间轴，空心圆点一路排下去，终点是一个实心点，表示"到这里了"。

暗色模式

右上角有一个按钮。白天用暖白底，晚上用深炭底。你的选择会被记住，下次打开还是那个样子。

它还在长

这个主题是为我自己写的，所以它只做我需要的东西。以后想到什么顺手的小功能，会继续加进来。它不会变成一个大而全的主题，它只是这个博客的皮肤。

写于雾还没散的那个早上。

—— 一个写给自己的主题
