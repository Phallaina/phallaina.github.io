短代码速查

这篇文章用来演示 Mist 主题自带的几个短代码（shortcode）。写文章时直接在 markdown 里插入对应写法即可，下面每个效果下面都附了可直接复制的代码。

折叠框

长引文、题外注释、想留给自己看的话，可以折起来。

一段不必展开的回忆
那年冬天的海是灰的。我们站在堤坝上，谁也没说话，风把围巾吹得像一面旗。 后来我才明白，有些沉默是有重量的。
{{< collapse title="一段不必展开的回忆" >}}
折叠内容写在这里。
{{< /collapse >}}

文中小标签

行文中需要轻轻标一下词时用。默认是浅灰底胶囊，加 outline="1" 变成描边样式。

有些瞬间 不可复制 ，它们像雾，来了就散了。描边样式： outline 。

有些瞬间{{< tag >}}不可复制{{< /tag >}}，它们像雾。
描边样式：{{< tag outline="1" >}}outline{{< /tag >}}。

小提示

正文里需要插一条备注、一个补充说明时用。title 可选，不加就只显示内容。

注
这里写一句不必打断主线、但又值得留下的话。它和正文同色，但被一个浅灰底托住，眼睛扫到这里会自然慢一下。
{{< note title="注" >}}
这里写提示内容。
{{< /note >}}

按钮链接

文中偶尔要放一个外链接，比纯链接醒目一点，但又不是卡片。

回到首页
{{< btn href="https://phallaina.github.io" >}}回到首页{{< /btn >}}

GitHub 仓库卡片

技术笔记里提到某个项目时用。stars 和 desc 都是可选。

gohugoio / hugo
The world's fastest framework for building websites.
★ 80.2k
{{< github repo="gohugoio/hugo" stars="80.2k" desc="一句话描述" >}}

多标签页

写同一个主题的几个并列方案、或者并列几种状态时用。标签名用逗号分隔，各标签内容用 --- 分隔。

雾还没散，海的边界是模糊的。光线是灰的，声音也是。

太阳出来了，海面碎成一片一片的银。风停了，云走得很慢。

灯塔每隔几秒扫过一次，光落在水面上，像一句没说完的话。

其他

  • 引用用普通 > 即可
  • 分隔线用 ---
  • 图片直接 ![]()
